## How the ₹999 shows up (backend patch, `2026-10-29-backend-diwali-999-offer.patch`)

`services/laundry-paywall-offer.js` reads `LAUNDRY_PAYWALL_OFFER` (name, from, until, plans, prices, planIds). While the window is open, `/billing/status` and `/billing/subscribe` apply it to every shop whose latest subscription is not active/authenticated: plans = yearly only, annual price ₹999, Razorpay plan = the ₹999 yearly plan, no ₹2 trial. Shops on a plan are untouched. Apps 1.0.13+ draw "yearly only · ₹999"; older apps and the website show both plans with ₹999 on yearly. `Paywall Shown {variant: "offer:diwali999"}` and profile `Paywall_Variant` stay as before (the group is not changed), so the offer is read from `variant` on the paywall events. After `until`, standard prices return by themselves; the link keeps working.

Link: **https://mylaundry.work/pay/diwali999** — the existing `/pay/<code>` route: Android → `mylaundry://subscription` (app 1.0.8+) else Play Store; desktop → Play Store / website. The web paywall is the hard gate after login on mylaundry.work.
