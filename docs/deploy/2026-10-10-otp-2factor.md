# Deploy: OTP login via 2Factor instead of MiniMoth (2026-10-10)

Login OTPs are now sent and checked by [2Factor](https://2factor.in) — SMS OTP
API, docs: https://documenter.getpostman.com/view/301893/TWDamFGh. Backend
only; web and Android call the same `/api/laundry/auth/*` routes and don't change.

- **Backend**: new `2factor` provider in `services/laundry-otp.js`.
  - Send: `GET https://2factor.in/API/V1/{key}/SMS/{phone}/AUTOGEN[/{template}]`
    — 2Factor generates and sends a 6-digit code (the app asks for 6 digits).
  - Verify: `GET .../SMS/VERIFY3/{phone}/{otp}` — by phone, so no schema change;
    "OTP Matched" → valid, "OTP Mismatch" → wrong OTP (uses an attempt),
    "OTP Expired" → expired, anything else → 503 "try again shortly".
  - Cooldown, daily limit, 5-attempt cap and the review numbers
    (`10000000xx`, OTP `10000` + last digit) are unchanged and still never hit SMS.
  - MiniMoth stays in the code; switching back is one env var.
- **Env** (`backend/.env`, not in git):
  ```
  LAUNDRY_OTP_PROVIDER=2factor
  LAUNDRY_2FACTOR_API_KEY=<2Factor API key>
  # LAUNDRY_2FACTOR_TEMPLATE=<OTP template name>   # optional, DLT template from the 2Factor dashboard
  ```

## Backend (courses-aws, `~/shweta-makeup-monorepo/backend`)

**Android autofill:** the app's SMS Retriever only fills the code when the SMS
ends with the app hash `L0M29zKHAPt`. 2Factor's default OTP SMS doesn't carry
it, so until a DLT-approved OTP template that ends with the hash is added in the
2Factor dashboard (SMS OTP → OTP Templates) and its name set as
`LAUNDRY_2FACTOR_TEMPLATE`, owners type the code by hand.

**Without a template 2Factor delivers the OTP as a voice call**, not SMS. Live
since 2026-10-10 13:25 UTC: `LAUNDRY_2FACTOR_TEMPLATE=OTP Verification Template 1`
(sender MYLAUN, "Your MyLaundry verification code is XXXX L0M29zKHAPt",
approved) — SMS only, and it carries the autofill hash.

Rollback: set `LAUNDRY_OTP_PROVIDER=minimoth` in `backend/.env` and
`docker compose -f docker-compose.prod.yml up -d backend` (the MiniMoth key is
still there).
